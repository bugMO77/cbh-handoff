## 2. Statements explicitly supported by the provided video-transcript material

The following are reported as things the creator stated in the supplied transcripts.
They are recorded as `DOCUMENTED_CLAIM` (creator statements), not as independently
verified facts:

1. The creator shares the project **prompts and file-tree structure** on GitHub.
2. Viewers may **take the shared file-tree structure, modify it, and work with it**.
3. The project is intended as a **starting point that users can customize and improve**.
4. Users should **understand the architecture and instructions** rather than blindly
   download and run the project.
5. Users should **review generated files and instructions, correct mistakes, and gradually
   improve** the project.
6. **Skills, scripts, prompts, and the learning process need continuous refinement.**
7. **More instructions do not automatically produce a better agent**; context overload and
   instruction quality matter.
8. **The human operator must supervise the agent**, understand its decisions, and validate
   results.

The transcripts also describe design elements (scope restriction, on-demand skill loading,
false-positive gates, evidence requirements, specialised subagents, persistent target
workspaces, prioritisation, exploit/impact validation, historical context retrieval,
writeup ingestion, agent briefing/commands, browser/MCP integration, continuous skill
improvement). These are **descriptions of the project's design**, not separate permission
grants.
