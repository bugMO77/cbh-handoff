# EVIDENCE_LIMITATIONS.md

## Purpose

This document separates **observed facts**, **documented claims**, **implemented (but
unexecuted) behaviour**, **tested behaviour**, **inferences**, **unknowns**, and **failed
inspection attempts** for every source in this package.

No source was executed, trained, or integration-tested. The package is static evidence plus
bounded, read-only sampling.

## 0. Evidence taxonomy

| Label | Definition |
|-------|------------|
| `OBSERVED_FACT` | Directly verified by reading a file, parsing data, or comparing hashes |
| `DOCUMENTED_CLAIM` | Asserted by the source's own documentation; not independently verified |
| `IMPLEMENTED` | Code exists and was read; not executed |
| `CONFIGURED` | Configuration exists; not exercised |
| `TESTED` | A test actually ran and passed — **not achieved in this package** |
| `INTEGRATION_VERIFIED` | End-to-end runtime behaviour verified — **not achieved** |
| `INFERENCE` | Reasoned conclusion from consistent evidence |
| `UNKNOWN` | Insufficient evidence |
| `UNVERIFIED` | Conflicting or ambiguous evidence |
| `FAILED_INSPECTION` | An inspection or retrieval attempt that did not succeed |

## 5. Inferences

### CBH
- **Medium:** the skill layer behaves as two products — engine arsenal (58 `hunt-*`) and
  harness-native knowledge base (83 auto-activated). Evidence: mapper routing vs host
  harness loading.
- **Medium:** "discoverable/loadable" depends on loading context, because the engine defaults
  to `skills_on=False`.
- **Medium:** CLI/engine overlap is an unresolved architectural concern.

### Ai-Hunting
- **Medium:** `runtime/registry.json` plus `ORCHESTRATION.md` is more likely the live design
  than the unregistered front-matter agent set, because the registry is machine-readable and
  referenced by `scripts/skill_registry.py`. Not verified at runtime.
- **Low:** the duplicate skill trees (`skills/` and `.agents/skills/`) are maintained by a
  generation step; `registry.yml` runs `skill_registry.py generate` and checks for drift.

### OffsecCyber
- **Medium:** the 51.2% synthetic share may dominate learned behaviour if used for training.
- **Medium:** class backfill is algorithmic (CWE→class map over 183 CWEs) and not
  human-verified.
- **Medium:** the viewer failure is caused by the same per-source schema heterogeneity seen
  in the samples.
